# Support

## Where to get help

- **Usage questions and workflows:** GitHub Discussions on this repository.
- **Bug reports and reproducible defects:** GitHub Issues using the bug report form.
- **Feature proposals:** GitHub Issues using the feature request form.
- **Security problems:** see `SECURITY.md` and report privately through GitHub Security
  Advisories, never a public issue.
- **GitHub Copilot CLI or account problems:** use GitHub's own support channels when the problem
  is on their side.

## Before asking

1. Check the README troubleshooting section and `docs/troubleshooting.md`.
2. Search existing issues and discussions.
3. Reproduce on the latest npm release with a clean environment and one provider key.

## What support covers

This is a free, maintainer-run project. Support covers defects in the latest release and
questions about documented behavior. It does not cover customized deployments, third-party
providers, or consulting work.

Never include API keys, tokens, or provider credentials in a support request.

## Response expectations

Best effort, usually within a week. Issues without version information or a reproduction may be
closed with a request for details.
